# Sources
All copies are byte copies made by `prepare_data.py` (run once by hand) or the saved job outputs; `data/member_cfgs.json` is a programmatic subset made by the same script.
- `ens-ext-1197079.out`, `ens-search-1197719.out`, `tier1-1082033.out`, `swa-ens-1094775.out`, `ens-max-1091645.out`: Kaya job logs of the same ids.
- `data/dumps_Faug_val__hyps_LP=*.jsonl`, `data/dumps_Faug_test__hyps_LP=0.8.jsonl`, `data/log_Faug_test.log`: `results/dumps_Faug_val|test`, `results/log_Faug_test.log` (rebuilt ensemble, local MPS decodes, 16 Sep 2026).
- `data/dumps_G1_test__hyps_LP=0.7.jsonl`: `results/ensemble_six_duration_two_fusion_decodes/` (local decode, 10 Sep 2026).
- `data/vd_xmodal_31205__*` (decodes and logs), `data/vd_xmodal_31205__g1_readout.txt`: `results/video_disjoint_cross_modal_ensemble/{decode,prior}` and `results/video_disjoint_cross_modal_ensemble/g1_readout.txt` (jobs 31204/31205, the read-out that selects the baseline single model on video-disjoint validation); `data/t2_vdens_10674__*`: `results/t2_vdens_10674/` (job 10674).
- `data/member_cfgs.json`: the `cfg` stored in each checkpoint, reduced to training manifest file name, pose augmentation flag, whether RGB features were used, keypoints, normalisation, epochs, learning rate and schedule, batch size, seed, plus the checkpoint md5. Checkpoints: `results/pose_augmentation_decodes/ckpts/pa_aug_s{42,101,202}/best.pt` (job 1215231), `results/ckpts_fus/{rgb_fusion,fus_s101}/best.pt`, `results/ckpts_r111/s{42,101,202}/best.pt` (stitch-scl2 jobs 1196567/1199393). The checkpoints themselves are not copied.
- Already published and read in place: `results/ensemble_member_subsets_ablation/` (jobs 120153, 120154), `results/final_ensemble_test_decodes`, `results/final_ensemble_validation_decodes`, `results/final_ensemble_member_test_decodes`, `results/ensemble_three_duration_members_decodes`, `results/ensemble_three_duration_two_fusion_decodes`, `results/ensemble_one_to_one_duration_members_decodes`, `results/semantic_adequacy_grading/hyps_{dwpose_ctc,vlp,rgbfusion}.jsonl`, `results/train_target_hashes.txt`, `jobs/slurm/ens_subsets.sbatch`.
