# Sources

- `seedens_rows.json`: byte copy of `results/seedens_21736/seedens_rows.json`, the per-batch rows written by `tools/seedens_analysis.py` for the seed-ensemble replication (Kaya job 21736, CPU).
- `members_config.json`: written once by `prepare_data.py` (not run by make) from the six local checkpoints `results/ckpts/comm_dwpose_{ctc_vlplong80,rgb_fusion,vlp_ctc,ctc_s202,fus_s101,fus_s202}.pt` (Kaya runs of Aug-Sep 2026, copied from `/group`). It holds only the training config stored in each checkpoint (epochs, seed, batch size, init_encoder path tail, whether RGB features were used) and tensor counts; no weights. Parameter count = values in the checkpoint's tensors without the fixed position tables (`pe` buffers, `slt/model.py` line 33).
- Read in place from files already published in the repository: `results/final_ensemble_test_decodes/hyps_LP=0.3.jsonl` and `hyps_MBR-WER.jsonl` (reported ensemble, beam 10, test decode of Kaya jobs 1101828/1125067), `results/final_ensemble_member_test_decodes/<member>/hyps_LP=0.3.jsonl` (the six members decoded alone with the same tool), `results/semantic_adequacy_grading/hyps_*.jsonl` (three single models, beam 5 and greedy, jobs 1075705/6806 ladder), `results/train_target_hashes.txt`, `jobs/slurm/mbr_wer_test2.sbatch` (member list), `jobs/slurm/gpu_batch_10h.sbatch` and `jobs/slurm/dwpose_vlp.sbatch` (pre-training epochs).
- The training manifest and the test references come from `make data` (`comm_run/manifests`).
