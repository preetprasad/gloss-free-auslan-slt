# Sources of the saved files

Every file is a byte copy or a programmatic subset of a saved output. `prepare_data.py` rebuilds `data/old/` (run once by hand with the cluster metrics files as argument); the subsets in `data/runs/`, `data/own/` and `data/recorded.json` were cut from the job folders below by a one-off script that was not kept (each is a column subset id, hyp, ref of the original decode file, or the score/epoch/settings fields of the job's own score and config files; the gate in `check.py` re-scores every one against the score its job recorded).

- `data/runs/<job>/<cell>.jsonl`: per-clip hypotheses and references (key `ref`) of the published systems' own code, test split, 800 clips each. Subsets of `w12l_test_dump.jsonl` in each run folder under `results/wave12l_138567/runs/` (job 138567, early-stopped runs), `results/wave12l2_167758/runs/` (job 167758, 200 epochs), `results/wave22_179411/runs/` (job 179411, seeds 303/404) and `results/wave12l4_239443/runs/` (job 239443, the authors' code retrained next to the 12l4 arms).
- `data/own/<job>/<arm>_s<seed>.b5.jsonl` and `.prot.jsonl`: per-clip hypotheses and references of this project's translator (beam width 5, and the authors' decoding protocol), subsets of the decodes in `runs_own/` of `results/wave12l2_167758/`, `results/wave22_179411/` and `results/wave12l4_239443/` (jobs 167758, 179411, 239443).
- `data/recorded.json`: for each file above, the score the job itself recorded (used only as a gate), the epochs completed, the training configuration and the beam width, from the same job folders (`w12l_scores.json`, `w12l2_guard.json`, run configs).
- `data/old/` (older single runs; for none of them is a hypothesis file kept, searched for in the run folders and `results/legacy_runs/`: they hold only train.log, metrics.json or progress.json, and a checkpoint):
  - `dwpose_d512.metrics.json` (7.11) and `dwpose_full.metrics.json` (7.92): byte copies of the `metrics.json` written by the cluster runs `comm_dwpose_d512` (script `jobs/slurm/dwpose_d512.sbatch`) and `comm_dwpose_full` (script `jobs/slurm/train_dwpose.sbatch`), fetched on 30 Oct 2026 (out_dir in each config names the run).
  - `exact_slt_run_summary.json` (2.08, 1.55): copy of `results/runs/communication_signjoey_direct_xywh_partial_2026-08-05.json`, the run summary written on 5 Aug 2026 for the stopped run; `exact_slt_train.log` and `exact_slt_progress.json`: copies of `comm_signjoey_direct_xywh_full/train.log` and `out/progress.json`. The test scores exist only in the run summary (no metrics.json or decode was kept), so they are read.
  - `signjoey_run_summary.json` (1.03): copy of `results/runs/communication_signjoey_slt_partial_2026-08-05.json` (same status as above); `signjoey_train.log`: copy of `comm_slt_signjoey_reference/train.log`.
  - `accum2_metrics.json`, `accum2_train.log`: copies of `comm_slt_1024_512_3x3_accum2/out/metrics.json` and `train.log` (greedy test 2.29; settings 60 epochs, 3e-4).
  - `checkpoint_cfgs.json`: training settings (12 fields) stored in `comm_slt_signjoey_reference/out/best.pt` and `comm_slt_1024_512_3x3_accum2/out/best.pt`, written by `prepare_data.py`; the checkpoints are not copied.
- `check.py`, `fragment.md`, `claims.json`, `SOURCES.md`, `prepare_data.py`: written for this check.
