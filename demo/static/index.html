How this example was made

The recorded example synchronises video and extracted pose, displays measured encoder features and self-attention, and compares the saved prediction with the dataset reference. A labelled schematic appears if the recording cannot be loaded.

The feature matrix shows activation values; a separate diagram shows self-attention. Neither establishes causal importance or sign-to-word alignment. Speech requires a separate, explicit action.
